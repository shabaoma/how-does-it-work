# How Does It Work?

This site uses diagrams and step-by-step explanations to make familiar technologies easier to understand. Explore questions such as how email codes help you sign in, how banks verify cardholders during online payments, and how cloud services manage access.

- Access tokens and secret tokens

- OAuth 2.0 authorization code and PKCE
- OpenID Connect login
- Email verification code login

**Service integration**

- Webhook event notifications

**Distributed systems**

- Cache updates and invalidation

**Payments**

- 3D Secure payment authentication
- Payment idempotency

**Cloud services**

- AWS STS temporary credentials
- AWS IAM permissions

Choose a topic from the home page, or use the topic navigation to move between pages.

## How to read a page

1. Start with the overview diagram to see who is involved and how they connect.
2. Follow the numbered steps, or use the Previous and Next buttons. Read each diagram alongside its explanation.
3. Explore the additional notes for different scenarios and important limitations.

The pages describe common flows. Details may vary depending on the product and how it works.
